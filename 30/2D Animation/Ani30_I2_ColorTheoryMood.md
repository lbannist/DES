# Animation 30 – Color Theory & Mood Through Animation

## Unit I: World & Mood Building — Challenge I2

**Time:** 1 Week (4–5 Class Periods)
**Due Date:** Following Monday before class

---

## 🎯 Learning Objectives

By the end of this assignment students will:

- Apply color palette choices to shift emotional tone independent of character or motion
- Reuse the same scene with two distinct palettes to isolate color's effect
- Practice basic color grading in post-production
- Build directly on the environment created in Challenge I1

Students will learn that color is one of the most powerful — and most controllable — mood tools an animator has.

---

## 💭 Production Question

### Can the same exact scene feel like two completely different places?

This assignment reuses your I1 environment (or a similar new one) to isolate color as the only variable that changes.

---

## Checkpoint 1 — Research and Analysis (Day 1)

**📖 Color & Mood Study**

Study 2–3 scenes where color palette is clearly doing emotional work (a warm, golden-hour scene vs. a cold, desaturated one). Answer:

1. What emotion does each palette create on its own, before any action happens?
2. Which colors dominate each example, and what do they have in common (warm/cool, saturated/muted)?
3. How does color guide your eye through the scene?
4. Would the scene's story change if the palette were swapped?

---

## Checkpoint 2 — Planning (Day 1–2)

**✏️ Choose Your Two Palettes**

Using your I1 environment (or a new simple scene), plan two contrasting color treatments — for example, warm/inviting vs. cold/tense.

**Plan**

- Choose 3–4 dominant colors for each palette
- Note which elements of the scene will change color (lighting, background, key objects) and which stay neutral
- Predict, in writing, what emotion each palette should create before you build it

---

## Checkpoint 3 — Production (Days 2–4)

**✏️ Build both color versions of your scene in Krita, using your plan from Checkpoint 2 as your guide.**

**Document Settings**

- 1920 × 1080
- 12 FPS

**Requirements**

- Same scene, two full color treatments (Version A and Version B)
- Each version 6–10 seconds
- Use basic color grading (adjustment layers, overlays) as a finishing step on at least one version
- No changes to composition or motion between versions — color must be the only variable

---

## Checkpoint 4 — Reflection (Day 5)

**✏️ Answer:**

1. Which palette worked better for the story you imagined, and why?
2. Did the emotional effect match your Checkpoint 2 prediction? What surprised you?
3. How did color grading change the scene beyond just the base color choices?
4. If you showed both versions to a classmate without context, what do you think they'd assume about each one?

## 📊 Assessment Criteria

**Color & Mood Execution (40%)**

- Clear, distinct emotional effect between the two palettes
- Purposeful color choices, not arbitrary

**Technical Skill (30%)**

- Effective use of color grading/adjustment layers
- Composition and motion held constant between versions

**Consistency (20%)**

- Both versions match in all aspects except color

**Reflection (10%)**

- Thoughtful comparison of predicted vs. actual emotional effect

---

## 💡 Key Lesson

Color doesn't just decorate a scene — it directs how an audience feels before they've even processed what's happening.
