# Architectural Design 12 – Alberta Building Code Research

## Unit H: Advanced Documentation & Building Systems — Challenge H2

**Time:** 1 Week (3–4 Class Periods)
**Due Date:** *[insert due date]*

---

## 🎯 Learning Objectives

By the end of this assignment students will:

- Navigate the Alberta Building Code (ABC) and locate sections relevant to a residential or small commercial design
- Apply specific code requirements for egress, occupancy, and fire separation to a real design
- Identify where a design as drawn does not currently meet code, and revise it
- Communicate code compliance clearly and specifically, citing actual section numbers

---

## 💭 Production Question

### Would your design actually get a building permit?

---

## Checkpoint 1 — Code Navigation & Occupancy Classification (Day 1)

**✏️ Find Your Way Around the Code**

1. Using the Alberta Building Code (or provided excerpts), identify the occupancy classification that applies to your design (e.g., Group C for residential).
2. Locate and record the specific ABC sections governing egress requirements for your occupancy type.
3. Locate and record the specific ABC sections governing fire separation requirements relevant to your design (e.g., between a garage and living space, or between suites).

**Requirements**

- Correct occupancy classification identified
- Specific ABC section numbers recorded for egress and fire separation

---

## Checkpoint 2 — Applying Code to Your Design (Day 2)

**✏️ Check Your Own Building Against the Code**

1. Using your H1 (or an existing) floor plan, check every occupied room for a compliant path of egress and note the travel distance.
2. Check required fire separations against what's actually shown in your plan (e.g., garage-to-house separation, any required fire-rated assemblies).
3. Flag at least two places where your current design does not meet code as drawn.

**Requirements**

- A marked-up floor plan showing egress paths and travel distances
- Fire separation requirements checked against the plan
- At least two non-compliance issues identified and flagged

---

## Checkpoint 3 — Revision & Compliance Memo (Day 3)

**✏️ Fix It and Prove It**

1. Revise your Revit model to resolve the non-compliance issues flagged in Checkpoint 2.
2. Write a short code compliance memo summarizing the occupancy classification, key code sections applied, and how your design meets each requirement — citing section numbers throughout.
3. Produce a revised floor plan showing the corrected egress paths.

**Requirements**

- Revised model resolving flagged issues
- A code compliance memo citing specific ABC sections
- A revised floor plan showing corrected egress

---

## Checkpoint 4 — Reflection

**✏️ Answer:**

1. What code requirement most changed your design, and how?
2. Where did code requirements conflict with your original design intent, and how did you resolve the tension?
3. What's one code section you now understand well enough to apply again without looking it up?
4. Why does code research matter even in a competition or portfolio project where no one is actually pulling a permit?

## 📊 Assessment Criteria

**Code Navigation & Classification (20%)**

- Correct occupancy classification
- Accurate section numbers identified for egress and fire separation

**Application to Design (30%)**

- Thorough, accurate check of egress paths and fire separations
- Non-compliance issues correctly identified

**Revision & Compliance Memo (30%)**

- Design revised to resolve flagged issues
- Memo clearly and specifically cites applicable code sections

**Reflection (20%)**

- Thoughtful account of how code shaped design decisions

---

## 💡 Key Lesson

Code isn't a checklist you consult after the design is done — it's a constraint that's just as real as gravity, and the earlier you design with it in mind, the less you have to tear apart later.
