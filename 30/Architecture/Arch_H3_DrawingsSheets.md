## Checkpoint 1 — Wall Section (Day 1–2)

**✏️ Cut Through the Wall and Make It Buildable**

1. Select a representative exterior wall condition from your design and set up a wall section cut through it, from footing to roofline, at an appropriate detail scale (typically 1:20 or larger).
2. Confirm the section shows all major assembly layers: foundation/footing, floor structure, wall framing, insulation callouts, exterior cladding, and roof structure.
3. Add material callouts and dimensions (footing depth/width, wall height, insulation thickness, roof overhang), and cross-check the assembly against your H1 structural model and H2 code notes for consistency.

**Requirements**

- A wall section cut through a representative condition, at detail scale
- All major assembly layers visible, dimensioned, and tagged with material callouts
- Consistency check against structural and code work

---

## Checkpoint 2 — Stair Detail (Day 2–3)

**✏️ Get the Stair Right**

1. Set up a stair section/detail view (or, if your design has no stair, model a simple two-storey stair condition for this exercise).
2. Dimension rise and run for each step, and confirm they meet standard code minimums/maximums for residential stairs.
3. Annotate handrail height and any required guard height at the open side, if applicable.

**Requirements**

- A dimensioned stair section/detail
- Rise and run checked against code minimums/maximums
- Handrail/guard heights annotated

---

## Checkpoint 3 — The Anatomy of a Drawing Set (Days 4–5)

**✏️ Learn What Goes in the Front of a Real Set — Then Build It**

You already know how to build a basic title block from Grade 10. A real construction document set is built from more than a title block repeated on every page — it has a handful of specific lead pages, each doing a different job. Before assembling your set, research and understand each of these:

- **Cover / Title Sheet** — project name, address/site, client, design team, a key rendering or line-art image of the project, and a general project description. This is the "first impression" page.
- **General Notes Sheet** — the standard notes that apply across the whole project (materials, code edition referenced, abbreviations used, general construction requirements) so they don't need repeating on every drawing.
- **Code Summary Sheet** — a dedicated page presenting the occupancy classification, egress requirements, and fire separation requirements you researched in H2, so a plan reviewer can find your code compliance case in one place instead of hunting through the set.
- **Drawing Index / Sheet List** — a table listing every sheet in the set by number and name, in order, so nothing gets lost and everyone knows what should be there.
- **Key Plan** *(for larger or multi-area projects)* — a small reference diagram showing which part of the building a given sheet or detail is looking at.

Using an industry-style sheet numbering convention (e.g., A0.x general/cover, A1.x plans, A2.x elevations, A3.x sections, A4.x details), number and organize every sheet from H1–H3 (framing/foundation plan, floor plans, elevations, wall section, stair detail) into one set.

Build your cover sheet, general notes sheet, code summary sheet (using your H2 research), and drawing index, then assemble everything into a single coordinated CD set and export it as one combined PDF.

**Requirements**

- Cover/title sheet, general notes sheet, code summary sheet, and drawing index all completed
- A documented, consistently applied sheet numbering convention
- Drawing index that matches the actual sheet set exactly
- A single combined PDF export of the full, coordinated set

## Checkpoint 4 — Reflection

**✏️ Answer:**

1. What did zooming into detail scale (wall section, stair) reveal that your floor plan and section didn't show?
2. Before this challenge, what did you think a "drawing set" was — and how is that different from what you just built?
3. Which lead page (cover sheet, general notes, code summary, or drawing index) do you think matters most to a contractor, and why?
4. Where did you find an inconsistency (mismatched sheet number, a drawing missing from the index) once you actually checked your own set?

## 💡 Key Lesson

The building lives or dies in the details — but a set of great details no one can find or trust is just as useless as no details at all. A real drawing set earns its credibility one lead page at a time.
