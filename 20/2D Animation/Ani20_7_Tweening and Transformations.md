## 🎯 Learning Objectives

By the end of this assignment students will:

- Use transform tools effectively

---

## 💭 Production Question

### How can an animator create motion without drawing new frames?

Many professional animations rely heavily on transforms and keyframes.

Transform animation allows artists to create motion while reusing existing artwork.

[![Watch the video](https://img.youtube.com/vi/EJcDSt29FHw/maxresdefault.jpg)](https://youtu.be/EJcDSt29FHw)

## Checkpoint 1 — Analysis (Day 1)

**📖 Find one example each of:**

- A motion graphics piece (e.g. a title sequence or explainer video)
- A UI animation (e.g. an app or website interaction)
- A logo reveal
- A floating object animation (e.g. a game or motion-graphics loop)

**✏️ Answer the Observation Questions in a short written response, using your examples as reference (a few sentences per question is enough).** Keep this — you'll build on it in Checkpoint 2.

1. Which objects are actually being redrawn?
2. Which objects are simply transformed?
3. How does timing affect motion quality?

---

## Checkpoint 2 — Planning (Day 1)

**✏️ Choose one project:**

- Animated logo
- Floating drone
- Magic artifact
- Interface animation
- Original approved concept

**Plan**

Sketch your object(s) and note, for each one:

- Which transforms it will use (position, scale, rotation, opacity)
- Its starting state and ending state for each transform
- Which parts (if any) will be hand-drawn rather than transformed

---

## Checkpoint 3 — Animation Production (Days 2–4)

**✏️ Build your animation in Krita, using your plan from Checkpoint 2 as your guide.** Set up your objects and keyframe their transforms so the animation meets the requirements below.

**Requirements**

- 5–10 second animation
- Minimum 3 animated objects
- Use position, scale, rotation, and opacity (at least once each across the animation)
- Maximum 5 hand-drawn frames

---

## Checkpoint 4 — Reflection (Day 5)

**✏️ Answer:**

1. How many drawings were created?
2. How many transformations were used?
3. What work was saved through transforms?
4. Which transform was most effective?
