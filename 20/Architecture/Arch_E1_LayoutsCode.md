## 🎯 Learning Objectives

By the end of this assignment students will:

- Plan an office floor layout that meets basic accessibility clearances
- Apply corridor width, door swing, and washroom clearance requirements to a real layout
- Recognize how code-driven constraints differ from the residential design in Units C and D
- Block out a commercial floor plan at an appropriate scale for its program

---

## 💭 Production Question

### What has to be true about a space before anyone even gets to "design" it?

---

## Checkpoint 1 — Program & Code Research (Day 1)

**✏️ Set Requirements Before Laying Anything Out**

1. Define your office program: number of private offices, open workstation area, meeting room(s), reception, and washroom(s).
2. Research (or apply provided reference values for) minimum corridor widths, door swing clearances, and accessible washroom clearances.
3. Sketch a rough bubble diagram of the program, noting where code clearances will most affect the layout (corridors, washroom, accessible route from entry).

**Requirements**

- A documented office program
- Minimum clearance values identified for corridors, doors, and washrooms
- A rough bubble diagram noting where clearances matter most

---

## Checkpoint 2 — Floor Layout (Days 1–2)

**✏️ Model the Office Layout in Revit**

1. Lay out interior walls for private offices, open workstation area, meeting room, and reception according to your program.
2. Check corridor widths against your researched clearances, adjusting wall placement where needed.
3. Lay out the washroom(s) with correct accessible clearances (turning radius, fixture spacing).
4. Verify door swings don't conflict with corridors, other doors, or fixtures.
5. Save your file using a version-numbered name (e.g., `LastName_E1_OfficeLayout_v01.rvt`).

**Requirements**

- Complete interior layout matching the program
- Corridor widths meeting minimum clearances
- Washroom(s) laid out with correct accessible clearances
- No conflicting door swings

---

## Checkpoint 3 — Reflection

**✏️ Answer:**

1. What clearance requirement most changed your original layout idea, and how?
2. Where did you have to redesign after checking a code clearance you hadn't originally planned for?
3. How is designing to code constraints different from the residential work you've done so far?
4. Why do accessibility clearances matter beyond just "meeting the code"?

## 📊 Assessment Criteria

**Program & Research (20%)**

- Clear program defined
- Correct clearance values identified before layout began

**Floor Layout (40%)**

- Layout meets corridor, door, and washroom clearance requirements

**Technical Execution (20%)**

- Model is clean and clearly organized

**Reflection (20%)**

- Specific example of a clearance-driven redesign
- Clear understanding of why the constraint matters

---

## 💡 Key Lesson

In commercial work, code clearances aren't a limitation on design — they're the first design constraint you solve for, before style or aesthetics ever enter the conversation.
