## 🎯 Learning Objectives

By the end of this assignment students will:

- Build a multi-level residential model from a guided tutorial, following documentation conventions
- Use Revit's Levels, multi-level walls, and stair tools to construct a two-storey (or more) building
- Follow a professional modeling sequence rather than working out of order

---

## Checkpoint 1 — Levels & Shell (Day 1)

**✏️ Set Up the Building's Levels and Exterior Walls**

1. Open the Island Villa tutorial start file (or set up new Levels if starting from scratch) and confirm each Level is named and set to the correct elevation (Level 1, Level 2, Roof, etc.).
2. Sketch the ground-floor exterior walls on Level 1, following the tutorial's plan dimensions.
3. Copy or re-sketch the upper-level walls on Level 2, checking that they land correctly over the walls below.
4. Add a basic roof over the shell so the massing reads correctly in 3D view.
5. Save your file using a version-numbered name (e.g., `LastName_C1_IslandVilla_v01.rvt`) so you have a checkpoint to return to.

**Requirements**

- At least two Levels correctly named and set to the right elevation
- Exterior walls modeled on both levels, aligned floor to floor
- A roof present over the shell
- File saved with a clear, version-numbered filename

---

## Checkpoint 2 — Interior Layout & Stairs (Days 1–2)

**✏️ Add Interior Walls and Vertical Circulation**

1. Lay out interior partition walls on Level 1 following the tutorial's room layout.
2. Add a stair connecting Level 1 to Level 2, using Revit's Stair tool, and check that headroom and landing clearances look reasonable in section.
3. Lay out interior partition walls on Level 2, making sure they land on structure below where required.
4. Add doors and windows to both levels following the tutorial.
5. Run a 3D section box through the stair to confirm it connects both levels cleanly with no floating or overlapping geometry.

**Requirements**

- Interior walls placed on both levels
- A working stair connecting Level 1 and Level 2
- Doors and windows placed on both levels
- No floating, overlapping, or misaligned geometry when checked in section

---

## Checkpoint 3 — Reflection

**✏️ Answer:**

1. What was different about working with two levels instead of one, compared to your Grade 10 tiny home?
2. Where did the stair cause problems (headroom, landing space, alignment), and how did you fix them?
3. Why does the order you model in (levels → shell → interior → stairs) matter?
4. What's one modeling habit from this tutorial you plan to keep using for the rest of the unit?

## 📊 Assessment Criteria

**Levels & Shell (25%)**

- Levels correctly named and set to accurate elevations
- Exterior walls and roof modeled cleanly on both levels

**Interior Layout & Stairs (35%)**

- Interior walls placed accurately on both levels
- Stair models correctly with reasonable headroom and landing space
- Doors and windows placed appropriately

**Technical Execution (20%)**

- No floating, overlapping, or misaligned geometry
- File organized with clear, version-numbered saves

**Reflection (20%)**

- Thoughtful, specific reflection on the modeling process
- Clear identification of what was different about multi-level work
- Concrete takeaway carried forward into later challenges

---

## 💡 Key Lesson

Multi-level buildings force you to think in section as much as in plan — every wall, stair, and floor has to line up with what's directly above and below it, not just look right from the top.
