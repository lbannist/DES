# Architectural Design 11 – Construction Document Set

## Unit D: Custom Home Design & Documentation — Challenge D3

**Time:** 1 Week (3 Class Periods)
**Due Date:** *[insert due date]*

---

## 🎯 Learning Objectives

By the end of this assignment students will:

- Compile a cover sheet, floor plans, elevations, and section into one coordinated sheet set
- Set up consistent sheet numbering and a title block across a project
- Organize a drawing set the way it would be delivered on a real project
- Proofread a drawing set for consistency and completeness

---

## 💭 Production Question

### What makes a set of drawings feel like ONE document instead of a folder of separate files?

---

## Checkpoint 1 — Sheet Setup (Day 1)

**✏️ Build the Sheet Structure**

1. Set up a title block with your name, project title, date, and a placeholder for a sheet number/name on every sheet.
2. Create a cover sheet listing the project name, a small 3D view or rendering, and a sheet index.
3. Place your floor plan(s) from Challenge D1 onto dedicated, correctly-scaled sheets.
4. Place your elevations and building section from Challenge D2 onto dedicated sheets.
5. Assign a consistent sheet numbering system (e.g., A0.0 Cover, A1.0 Floor Plans, A2.0 Elevations, A3.0 Sections).

**Requirements**

- Title block consistent across all sheets
- Cover sheet with project info and a sheet index
- Floor plans, elevations, and section each on their own correctly-scaled sheet
- Consistent, logical sheet numbering

---

## Checkpoint 2 — Coordination & Cleanup (Days 1–2)

**✏️ Coordinate and Proofread the Set**

1. Check that every sheet's scale, north arrow, and drawing title are correct and consistent.
2. Cross-check that room names/numbers match between the floor plan and any schedules or call-outs.
3. Confirm the sheet index on the cover sheet accurately lists every sheet in the set, in the right order.
4. Review the full set printed or exported as one PDF — look for any sheet that reads unclear, mislabeled, or inconsistent with the rest.
5. Save your file using a version-numbered name (e.g., `LastName_D3_CDSet_v01.rvt`).

**Requirements**

- Scales, north arrows, and titles consistent and correct on every sheet
- Room names/numbers consistent across plan and schedules
- Sheet index accurately matches the set
- Full set reviewed as one exported PDF

---

## Checkpoint 3 — Reflection

**✏️ Answer:**

1. What's one inconsistency you found and fixed while proofreading your set?
2. Why does sheet numbering matter on a real project with dozens of sheets?
3. What's the purpose of a cover sheet and sheet index beyond looking professional?
4. If someone who had never seen your project opened this set cold, could they find what they needed? What would make that easier?

## 📊 Assessment Criteria

**Sheet Setup (30%)**

- Consistent title block and sheet numbering
- Cover sheet with accurate sheet index

**Coordination (35%)**

- Scales, titles, and north arrows consistent across sheets
- Room names/numbers consistent throughout

**Presentation (15%)**

- Set reads clearly as one coordinated document when exported

**Reflection (20%)**

- Specific, honest account of an inconsistency found and fixed
- Clear understanding of why coordination matters on real projects

---

## 💡 Key Lesson

A drawing set isn't finished when every sheet is individually correct — it's finished when the sheets agree with each other, and catching those disagreements is the real work of coordination.
