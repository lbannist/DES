# CAD 11 – Parametric Design

## Unit E: Parametric Design — Challenge E4 (Capstone)

**Time:** 1 Week (3–4 Class Periods)
**Due Date:** *[insert due date]*

## 🎯 Learning Objectives

By the end of this assignment students will:

- Independently combine every parametric skill built in Unit E into one design
- Derive at least one dimension from an external spec rather than a hardcoded value
- Build a parameter-driven pattern that remains valid across a full stated range
- Set up a design table to generate required variants in a single pass, with no notes or reference material

---

## 💭 Production Question

### Given a real problem and no instructions, can you actually design the way a parametric designer would?

---

## Checkpoint 1 — Understanding the Brief (Day 1)

**✏️ Read the Constraints and Plan Your Approach**

1. Review the supplied real object and its stated use-case constraints (for example: "must mount 3 different motor sizes," or "must work across a range of shelf widths").
2. Identify which dimension(s) must be derived from an external spec, which feature must be a parameter-driven pattern, and what range that pattern must survive without breaking.
3. Sketch a rough plan for your parameter structure before opening Fusion 360 — no notes or reference material may be used once modeling begins.

**Requirements**

- A short written plan identifying: the externally-derived dimension, the range-driven pattern, and the intended design-table variants
- No reference material consulted beyond the supplied brief

---

## Checkpoint 2 — Live Build (Days 2–3)

**✏️ Build the Model, Unsupported**

1. Model the part fully parametrically, with no notes or outside reference — this is a test of fluency, not a guided build.
2. Derive at least one key dimension from the external spec given in the brief, written as a formula.
3. Build a parameter-driven pattern (count and/or spacing) and test it at both extremes of the stated range to confirm it doesn't break or self-intersect.
4. Set up a design table and generate the variants required by the brief in a single pass.

**Requirements**

- At least one dimension correctly derived from an external spec via formula
- A parameter-driven pattern that remains valid across the full stated range
- A design table generating all required variants in one pass, no manual sketch edits
- Entire build completed with no tutorial, notes, or reference material

---

## Checkpoint 3 — Reflection

**✏️ Answer:**

1. Which of Unit E's earlier challenges (E1, E2, E3) did you draw on most directly here, and how?
2. Where did your pattern almost break at the edge of the stated range, and how did you catch it?
3. What would you have done differently if you'd had more time to plan before building?
4. Looking back across all of Unit E, what's the biggest shift in how you approach a new design problem now?

## 💡 Key Lesson

Parametric fluency isn't measured by whether you can follow a tutorial — it's measured by whether you can design under real, external constraints with nobody guiding your hand.
