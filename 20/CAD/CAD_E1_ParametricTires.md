## 🎯 Learning Objectives

By the end of this assignment students will:

- Build a fully parametric model using named user parameters rather than hardcoded sketch values
- Use revolve and wrap/project geometry to construct a functional tread pattern
- Understand how changing a single driving parameter can regenerate an entire model
- Produce multiple design variants from one parametric model

---

## 💭 Production Question

### What's the difference between a model that has dimensions and a model that has parameters?

---

## Checkpoint 1 — Building the Parametric Tire (Days 1–2)

**✏️ Follow the Parametric Tire Design Series**

1. Work through the provided parametric tire design series (6 videos), setting up user parameters for the driving dimensions before modeling any geometry.
https://www.youtube.com/playlist?list=PLLm7Yjr9z_z35RcdwKDTzw3Kg541mzxl2
2. Build the tire using revolve for the base profile and wrap/project geometry for the tread pattern.
3. Confirm every key dimension (diameter, tread depth, sidewall width) is controlled by a named parameter, not a fixed sketch value.

**Requirements**

- Complete parametric tire model following the tutorial series
- Named user parameters controlling diameter, tread depth, and sidewall width
- Tread pattern built using wrap/project geometry, not manually sketched around the tire

---

## Checkpoint 2 — Generating Variants (Day 3)

**✏️ Prove the Model Is Actually Parametric**

1. Change only the driving parameters (diameter, tread depth, sidewall width) — do not edit any sketch geometry directly.
2. Regenerate the model and confirm it updates correctly with no broken features or failed geometry.
3. Produce two visibly different tire variants from the same model using this method.

**Requirements**

- Two distinct tire variants produced by changing parameters alone
- No sketch geometry edited directly to create the variants
- Both variants regenerate cleanly with no errors

---

## Checkpoint 3 — Reflection

**✏️ Answer:**

1. What would have gone wrong if you had built this tire with hardcoded dimensions instead of parameters?
2. Which parameter had the biggest visual effect when changed, and why?
3. Did any feature break or behave unexpectedly when you changed a parameter? How did you fix it?
4. What's one part of this build where you can see why "parametric" is more than just a buzzword?

## 📊 Assessment Criteria

**Parametric Setup (35%)**

- Key dimensions correctly controlled by named user parameters
- Clean, logically named parameter list

**Modeling Technique (30%)**

- Correct use of revolve and wrap/project geometry for the tread

**Variant Generation (15%)**

- Two distinct, cleanly regenerated variants produced by parameter changes alone

**Reflection (20%)**

- Clear articulation of what parametric modeling makes possible
- Honest account of any issues encountered and how they were resolved

---

## 💡 Key Lesson

A model with dimensions can only ever be one thing — a model with parameters can become many things, as long as the relationships were built correctly from the start.
