# CAD 11 – Parametric Design

## Unit E: Parametric Design — Challenge E3

**Time:** 3–4 Class Periods
**Due Date:** *[insert due date]*

---

## 🎯 Learning Objectives

By the end of this assignment students will:

- Use a design table / configuration to generate multiple variants from a single parametric model
- Manage a family of parts from one file rather than editing parameters by hand for each version
- Understand design tables as a production workflow, not just a modeling trick
- Produce a documented set of part variants ready for real use

---

## 💭 Production Question

### If you needed twenty versions of this part by tomorrow, would your current workflow survive?

---

## Checkpoint 1 — Building the Base Parametric Model (Day 1)

**✏️ Set Up a Model Ready for a Design Table**

1. Choose a simple part to build as a family (a bracket, hook, or standoff), and model it fully parametrically using named user parameters.
2. Confirm the model regenerates cleanly when parameters are changed by hand before moving to the design table.

**Requirements**

- Fully parametric base model with named user parameters
- Confirmed clean regeneration through at least one manual parameter change

---

## Checkpoint 2 — Design Table & Variant Generation (Days 2–3)

**✏️ Generate a Family of Parts in One Pass**

1. Set up a design table / configuration linked to your model's parameters.
2. Build a spreadsheet of parameter values defining at least three distinct sizes or versions of the part.
3. Generate all variants from the design table and confirm each one regenerates correctly with no manual sketch edits.
4. Document each variant (screenshot or exported view) alongside its parameter values.

**Requirements**

- Design table set up and linked to the model's parameters
- At least three distinct variants generated from a single spreadsheet of values
- All variants regenerate cleanly with no manual fixes
- Each variant documented with its corresponding parameter values

---

## Checkpoint 3 — Reflection

**✏️ Answer:**

1. How is generating variants through a design table different from what you did in Challenge E1 or E2?
2. What would have gone wrong trying to make three variants by hand, one at a time, under a deadline?
3. Did any variant fail to regenerate cleanly? What caused it, and how did you fix it?
4. Where might this workflow be useful outside of school — in a real shop or product line?

## 📊 Assessment Criteria

**Base Parametric Model (25%)**

- Clean, fully parametric model ready for a design table

**Design Table Setup (35%)**

- Correctly linked design table generating the intended variants
- At least three distinct, correctly regenerated variants

**Documentation (15%)**

- Clear documentation of each variant and its parameter values

**Reflection (25%)**

- Clear articulation of the workflow's advantage over manual variant creation
- Honest account of any regeneration issues and how they were solved

---

## 💡 Key Lesson

A single parametric model is powerful — a design table turns that model into a production tool, generating a whole family of parts from one spreadsheet instead of one edit at a time.
